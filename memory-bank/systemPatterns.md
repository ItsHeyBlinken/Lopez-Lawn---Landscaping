# System Patterns

This is a static two-file site:

- `index.html` for structure, copy, and small page scripts
- `styles.css` for layout and brand colors

## Patterns to keep

- Single-page sections with in-page anchor navigation
- CSS variables for brand colors (forest green + gold)
- Mailto form handler that builds subject/body from the quote fields
- `tel:` and `sms:` links for the primary booking path
- No invented claims (years, certifications, customer names)
